Add real PNG icons here before deploying:
- icon-192.png (192x192)
- icon-512.png (512x512)

Quickest option: generate from a logo using https://realfavicongenerator.net
or `npx pwa-asset-generator logo.svg ./public/icons`.
Until these exist, the PWA install prompt / icon may not display correctly,
but the app itself will run fine.
